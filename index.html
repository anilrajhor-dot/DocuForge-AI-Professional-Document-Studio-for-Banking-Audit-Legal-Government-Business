Help & guidelines

Every tool lives under a Studio tab at the top. Most PDF tools need a file open first — that's why buttons look greyed out until you do. Here's what each Studio covers:

📄 PDF Studio

Add pages: Open/merge PDFs, insert a PDF at a specific position. Arrange: duplicate, rotate, reverse, delete, crop, and remove blank pages (checks actual pixels, so it works on scans too). Extract & split: pull selected pages into a new file, or split into many files by range or every N pages. Enhance: watermark, page numbers, Bates numbering, headers/footers, compress, and the metadata inspector.

🖼 OCR & Image Tools

Extract text from a photo, make a scanned PDF genuinely searchable (a real invisible text layer, not just a label), pull a table out of an image into CSV/Excel, combine images into a PDF, or export PDF pages as images.

🌍 Translation

Translate pasted text, an uploaded PDF/DOCX/TXT/MD file directly, or whatever PDF is currently open in the editor — across 38 languages, side by side. This sends the text you choose (never the file itself) to a translation service — the only exception to "everything stays on your device" besides AI tools.

🔄 Document Conversion

PDF to and from Word, Excel, CSV, HTML, JSON, XML, RTF, ODT/ODS/ODP, EPUB, and images. These carry over structure and text, not always exact original formatting — that's an honest limit of any browser-only conversion, not just this one.

📽️ PowerPoint Studio

Converts PDF → PowerPoint, PowerPoint → PDF, and PowerPoint → Markdown. The Markdown export extracts slide titles and text/bullets into a clean .md file. Structural, not visual — original slide design, images, animations and fonts are not preserved.

🤖 AI Assistant

Summarize, rewrite, simplify, generate meeting minutes, review a contract, or chat with a PDF — all using your own Anthropic, OpenAI, or Google Gemini API key, entered once and optionally remembered in your browser. There's no backend here to provide a shared key. If cost is a concern: Google's Gemini API (aistudio.google.com) has a genuinely free tier — no credit card, no expiration.

🌐 Website Studio

Describe a site — name, tagline, sections, style — and get a complete, unique single-file HTML website back, live-previewed and ready to download. Uses the same AI key as AI Studio.

📊 Spreadsheet Tools

Turn a spreadsheet into a chart, or digitize numbers out of a chart image (manual calibration — no software can reliably read an arbitrary chart automatically).

🔐 Security

Visual signature stamps, form fill & flatten, and beta password protection (a less battle-tested library than the rest of the app — verify the output opens correctly). Cryptographic digital signatures aren't supported; that needs a certificate authority.

📂 Batch Processing

Run one operation — compress, OCR, convert, watermark, or merge — across many files at once, and download everything as a single .zip.

📖 Reader

A dedicated reading view for PDF and EPUB, separate from editing — page navigation, zoom, themes, and a table of contents for EPUB chapters.

Stuck on something specific?

Tap the ? button in the bottom corner any time — type or speak a question and it'll try to answer directly, or point you to the right tool.

About DocuForge AI

Version: 2026.08.21.82 — if this doesn't match what you expect right after uploading a new version, your browser is showing a cached copy: try closing and reopening the tab, a hard refresh, or clearing Safari's site cache.

A privacy-first document toolkit that runs entirely in your browser — PDF editing, OCR, conversion, translation, and AI-assisted tools, with no backend and no document ever uploaded anywhere.

The two exceptions: Translate and AI Assistant send only the text you choose to a translation service or to the AI provider you supply your own key for — never your files, and never through any server of ours.

What's not supported in this edition: cryptographic digital signatures — that genuinely requires a certificate authority, no way around it in a browser tool. Password protection (both setting one and opening an existing password-protected PDF) is supported, but marked beta: it runs on a community-maintained fork of the core library, not the well-established one everything else here relies on.
